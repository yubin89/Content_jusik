# (나중에 진행) 기술 SEO 세팅 — Rank Math + 구글 서치콘솔

> 상태: **보류 — 방법만 정리해둠.** 나중에 "기술 SEO 하자" 하면 이 문서대로 진행.
> ⚠️ **중요**: 이걸 안 하면 글을 아무리 잘 써도 **구글 검색에 안 뜬다.**
> 이건 코드가 아니라 **워드프레스 화면 + 구글 계정에서 직접 클릭 세팅**하는 작업(1회성).

## 왜 필요한가
- seo_writer가 만드는 건 "콘텐츠 SEO"(글 자체). 하지만 구글이 사이트를 **발견·색인**하게 하려면
  "기술 SEO" 세팅이 따로 필요하다.
- 핵심 2가지: ① **Rank Math**(사이트맵·메타태그 자동화) ② **구글 서치콘솔**(구글에 사이트 등록).

---

## Part 1. Rank Math 플러그인 설치·설정

1. 워드프레스 관리자 → **플러그인 → 새로 추가**
2. 검색창에 **"Rank Math SEO"** → 설치 → 활성화
3. 설치 후 뜨는 **설정 마법사(Setup Wizard)** 따라가기:
   - 계정 연결(무료 계정 로그인 요구 시 구글로 간편 로그인)
   - 사이트 유형: **블로그** 선택
   - 나머지는 기본값으로 두고 진행 → 완료
4. 자동으로 생기는 것: **XML 사이트맵**(`moneyshot.co.kr/sitemap_index.xml`), 메타태그 관리, 구조화 데이터 기본값
5. (선택) Rank Math → 일반 설정에서 사이트맵 URL 확인해두기 (Part 2에서 씀)

> 대안: "Yoast SEO"도 동일 역할. 한국에선 Rank Math가 무료 기능이 더 많아 추천.

---

## Part 2. 구글 서치콘솔 등록 (제일 중요)

구글에 "내 사이트 있으니 색인해줘"라고 알리는 단계.

1. https://search.google.com/search-console 접속 → 구글 계정 로그인
2. **속성 추가** → **URL 접두어** 방식 선택 → `https://moneyshot.co.kr` 입력
3. **소유권 확인**:
   - 가장 쉬운 방법: **HTML 태그** 방식 → 구글이 주는 `<meta>` 코드 복사
   - 워드프레스 → Rank Math → **일반 설정 → 설정(연동)** 에 그 코드(또는 인증 코드) 붙여넣기
   - (Rank Math에 "구글 서치콘솔 연동" 메뉴가 있으면 그걸로 더 쉽게 연결 가능)
   - 다시 서치콘솔에서 **확인** 클릭
4. 소유권 확인되면 → **사이트맵 제출**:
   - 서치콘솔 왼쪽 **색인 → Sitemaps**
   - `sitemap_index.xml` 입력 → 제출
   - (Part 1에서 Rank Math가 만든 사이트맵 주소)

---

## Part 3. 첫 글 색인 요청 (선택, 빠른 노출용)

1. 서치콘솔 상단 **URL 검사** 창에 발행한 글 주소 입력
2. **색인 생성 요청** 클릭
- 새 사이트는 구글이 자동 색인하는 데 며칠~몇 주 걸림. 이 요청으로 조금 앞당길 수 있음.

---

## 참고 / 주의
- 소유권 확인 방식이 헷갈리면 Rank Math의 "구글 서치콘솔 연동" 기능을 쓰면 클릭 몇 번으로 끝남.
- 이 세팅은 **한 번만** 하면 됨. 이후 새 글은 사이트맵을 통해 자동으로 구글에 알려짐.
- 효과 확인: 며칠 뒤 구글에 `site:moneyshot.co.kr` 검색 → 글이 뜨면 색인된 것.
- 막히는 화면 있으면 캡처해서 물어보면 같이 봐줌.
