# (진행 예정) 레퍼런스 블로거 리서치 — AI 콘텐츠 + 애드센스

> 목적: 나와 비슷한 방식(AI 활용 콘텐츠 → 애드센스)으로 성공한 블로그를 찾아
> 발행주기·SEO·구조·수익화를 벤치마크한다.
> 상태: **리서치 투두 정리됨.** 아래 체크리스트대로 직접 조사 진행.

---

## ⚠️ 먼저 알아야 할 2026 현실 (중요)

1. **애드센스 수익 위기**: 구글 AI Overviews(검색결과 상단 AI 요약) 때문에
   많은 퍼블리셔가 **트래픽·수익 50~90% 급감**을 겪는 중. 애드센스 단독 의존은 위험.
   → **수익 다각화** 고려(제휴/쿠팡파트너스, 자체 상품, 뉴스레터 등).
2. **애드센스는 "자동생성 콘텐츠"를 거절·제한**함. 단, **AI 초안 + 사람 편집/팩트체크/
   실제 데이터**를 거친 글은 "자동생성"으로 분류되지 않음.
   → **우리 방식(초안 저장 후 사람이 검토·발행 + 실제 데이터 차트)이 정확히 안전한 쪽.**

## 우리가 이미 잘 맞춘 것 (조사로 확인)
- 성공 사례들의 발행주기 = **주 3~5회** → 우리 **주 3회**와 일치 ✅
- 사람 편집·팩트체크·구조화·실제 데이터 → 우리 **검토 후 발행 + 데이터 차트**와 일치 ✅
- 남발형 매일 자동발행은 애드센스 위험 → 우리가 피한 방향 ✅
