# style/ — 에이전트 학습 자산

코드 수정 없이 **작가/검수 에이전트를 고도화**하는 곳입니다.

- `rubric.md` — 검수 에이전트가 초안을 평가하는 체크리스트. 기준을 바꾸면 검수 방향이 바뀝니다.
- `examples/` — 작가에게 few-shot으로 주입할 예시. 아래를 넣으면 문체·품질이 학습됩니다.
  - 마음에 든 승인 글 전문(`.md`)
  - '수정 전 → 수정 후' 대비 예시 (무엇을 어떻게 고쳤는지)
  - 총 길이는 코드에서 상한(약 4000자)까지만 사용합니다. 좋은 예시를 소수 정예로.

## 운영 흐름 (초반 → 성숙)

1. 초반: `--max-rounds 1`로 돌려 초안·검수를 **직접 보며** 손보고, 잘 나온 결과를
   `examples/`에 저장 + `rubric.md`를 다듬는다.
2. 성숙: 품질이 안정되면 `--max-rounds 3 --pass-score 85`로 **무인 반복**,
   최종본만 확인하고 발행한다.
