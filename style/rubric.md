# SEO·콘텐츠 검수 체크리스트 (사용자 자산 — 자유롭게 수정)

검수 에이전트가 이 목록을 기준으로 초안을 평가합니다. 운영하며 원하는 기준을 추가/수정하세요.

## SEO
- 제목에 핵심 키워드가 자연스럽게 포함되는가 (32자 내외, 클릭 유도력)
- 메타 설명(description)이 120자 이내이고 검색결과에서 매력적인가
- 본문에 키워드/연관어가 억지 없이 반복되는가 (키워드 스터핑 아님)
- 소제목(H2)이 검색 의도(방법·비교·후기·추천 등)를 커버하는가
- 태그가 주제와 맞고 3개 이상인가

## 콘텐츠 품질 (E-E-A-T)
- 실제 경험·근거가 느껴지는가 (막연한 일반론 지양)
- 장단점/한계가 균형 있게 담겨 신뢰가 가는가
- 독자가 실제로 궁금해할 정보(가격대·사용감·대안)를 다루는가
- 과장·허위·없는 경험 지어내기가 없는가

## 구성/가독성
- 도입부가 독자 공감을 유발하는가
- 문단이 너무 길지 않고 스캔하기 쉬운가
- FAQ가 실제 궁금증을 반영하는가 (유형상 필요할 때)

## 감점 요인
- 제휴 링크만 있고 알맹이 없는 얇은 글
- 같은 문장·표현 반복
- 광고 카피처럼만 읽히는 톤
